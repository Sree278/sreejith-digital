# Instructions for anyone working on this repo (people and AI tools)

Site: https://sreejithdigital.com, the SEO consulting site of Sreejith CU. Static pages are generated by `scripts/generate_site.py` into `public/`; `/api/*` runs the Cloudflare Worker in `worker/index.js`. `main` deploys to production automatically.

## Read first

1. [`PROJECT-LOG.md`](PROJECT-LOG.md): the complete history and its **Logbook rules**.
2. [`SEO-STRATEGY.md`](SEO-STRATEGY.md): positioning, location policy, guardrails.
3. [`DEPLOYMENT.md`](DEPLOYMENT.md): infrastructure, secrets and owner checklist.

## Mandatory: keep the log book

Every PR that changes something core (site, Worker, Cloudflare or other dashboards, measurement, strategy, business facts) or records a decision **must add an entry to `PROJECT-LOG.md` in the same PR**, following the Logbook rules and entry template there: What, Why, When, Where, How, Evidence, Open. Work done outside the repo is logged in the next PR. A PR without its log entry is not finished.

## Other rules

- Work on a branch and open a PR; the owner merges. Never push to `main`.
- Run `python3 scripts/generate_site.py` after changing pages; `node --check` changed JS files.
- No secrets in the repo; they live in Cloudflare.
- Follow the guardrails in `SEO-STRATEGY.md` §14: no doorway pages, no invented results, no analytics before consent.
